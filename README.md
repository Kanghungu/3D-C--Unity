# 3D C# Unity

## 프로젝트 소개
- Unity 기반 3D SF 싱글플레이 RTS 프로토타입 프로젝트
- 우주 문명과 종교 전쟁 분위기를 가진 실시간 전투 중심 게임
- 시점은 약간 낮은 각도의 3D 전략 시점을 기준으로 한다
- 현재 목표는 완성작이 아니라 플레이 가능한 전투 프로토타입 제작
- 1인 개발을 전제로 범위를 작게 유지한다

## 현재 목표
- 카메라 조작
- 유닛 선택과 이동
- 기본 전투
- 간단한 생산 시스템
- 승패가 있는 중간 규모 전투 루프
- Windows PC에서 직접 실행 가능한 빌드 확보
- 혼자서 유지 가능한 구조와 문서 기준 만들기

## 사용 기술
- Unity
- C#
- Blender
- GitHub
- Codex

## 실행 방법
1. Unity Hub에서 이 폴더를 연다.
2. 프로젝트에 맞는 Unity 버전을 설치한다.
3. 메인 샘플 씬 또는 전투 테스트 씬을 연다.
4. Play 버튼으로 프로토타입을 실행한다.

## 현재 범위
- 싱글플레이만 고려
- 전투 프로토타입 우선
- 멀티플레이, Steam 연동, 대규모 캠페인은 제외
- 생산은 간단하게 시작하고, 기지와 자원 시스템은 후순위로 둔다
- 일정과 기능은 1인 개발 속도에 맞춰 보수적으로 잡는다
