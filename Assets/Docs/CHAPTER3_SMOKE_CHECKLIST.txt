챕터 3 — 본진·덱·자원·생산 (Battle Aces 정체성) 스모크
======================================================
**목표**: 자원·생산 큐·덱이 **왼쪽 HUD 한 패널**에서 읽히고, **랠리(Alt+우클릭)** 를 F1·짧은 힌트만으로 찾을 수 있으며, **T/Y/U** 업그레이드가 한 판에서 체감되는지 본다.

전제: `CHAPTER1`·`CHAPTER2` 스모크 통과 후.

왼쪽 HUD (NewSampleScene — 데모/스커미시)
-----------------------------------------
[ ] **작전 자원** 숫자·초당 수입·적 동원이 보임
[ ] **덱 1~8** 슬롯 이름이 보이고, 숫자 키로 주문 시 **생산** 블록이 갱신됨
[ ] **조선 중 / 대기 N기** 가 이해 가능(큐가 비면 안내 문구)
[ ] **집결(랠리)** 안내 줄이 보임
[ ] **본진 강화** — T/Y/U **다음 비용** 또는 만령 표시

랠리 (튜토리얼 없음)
--------------------
[ ] F1 요약에 왼쪽 HUD·랠리·Alt 가 언급됨
[ ] 전투 중 **Alt+지면 우클릭** 후 **하단 확인 문구**가 잠깐 뜸
[ ] 지면에 **청색 링** 이 보이고, 이후 생산 유닛이 그쪽으로 이동을 시작함

본진 업그레이드
--------------
[ ] 자원이 쌓이면 **T / Y / U** 로 1단계 이상 구매 가능(성공 시 확인음)
[ ] 생산(T)·장갑(Y)·자원(U) 중 **최소 1종**은 한 판에서 효과가 느껴짐(너무 느리면 수치 재조정 이슈)

편의(추가)
-----------
[ ] **Ctrl+A** — 아군 전체 선택 · **Esc** — 선택 해제
[ ] **,(쉼표)** — 집결(랠리) 지점으로 카메라
[ ] 덱 **1~8** 주문 불가 시 짧은 **거절음**(과도한 연타는 쿨다운)

콘솔: 빨간 Error 없음.

개발 마무리(코드 기준)
---------------------
- 왼쪽 HUD: `BattleAcesHudOverlay` — 자원·덱·생산·랠리·T/Y/U 다음 비용.
- 랠리 확인 토스트: `PulseRallyPointSetHint` ← `PrototypeSelectionController.Commands`.
- 본진 규칙·비용·업그레이드 키: `BattleAcesCore`.
- 조작 설명: `BattleAcesInGameHelp` (F1).

이슈 메모: 씬명, 콘솔 한 줄.
