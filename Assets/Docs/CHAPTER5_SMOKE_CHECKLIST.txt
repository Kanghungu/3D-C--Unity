챕터 5 — UI·피드백·온보딩 스모크
================================
**목표**: 상단 목표 바가 **데모 제목·목표·보조**로 읽히고, 미니맵·하단 선택 패널·**F1**이 실제 조작과 맞으며, 없는 시스템은 안내에 나오지 않거나 「이 데모에 없음」으로 구분된다.

전제: `CHAPTER1`~`CHAPTER4` 스모크 통과 후.

상단 목표 바 (UGUI)
-------------------
[ ] 캠페인 미션: 첫 줄 **「데모 · (미션 표시명)」** 형태
[ ] 둘째 줄: 목표 한 줄(예: 점령/방어/격파 등)
[ ] 셋째 줄: 플레이 힌트 + (해당 시) 점령·방어 동적 문구
[ ] 연습/스커미시: 첫 줄에 **「데모 ·」 접두 없음**(표시명만)

미니맵 · 선택 정보 HUD
-----------------------
[ ] 미니맵 위 한 줄에 시야·Shift+M·「표식」 안내가 보임
[ ] 하단 패널: 미선택 시 코어 HP + 상단/지도/F1 안내
[ ] 유닛 1기 선택 시 스탯 + 왼쪽 HUD·F1 안내

F1 인게임 도움
--------------
[ ] **핵심 요약**에 Battle Aces에 붙어 있는 입력만 나열
[ ] **R** = 승패 화면에서만 재시작으로 명시
[ ] **자세히**에 F1 vs F2~F5 부대 단축 설명 및 「이 데모에 없음」 블록
[ ] 공중 요새 변주 미션: 건물 클릭 선택 없음 문구 유지
