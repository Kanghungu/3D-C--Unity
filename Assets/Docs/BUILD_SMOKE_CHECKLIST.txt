Windows 빌드 짧은 스모크 (데모 우선)
====================================
File → Build Settings → Windows → Build 출력 후:

[ ] 실행 파일로 **CampaignMenu** 기동
[ ] **메인 → 데모** — 한 판(승 또는 패) — 결과 — 메인 복귀 · UI·입력·소리 깨짐 없음
[ ] (권장) 에디터와 다른 점만 메모 (해상도·전체화면·볼륨 등)

(옵션) 캠페인 미션 1 브리핑·전투 — 캠페인 에셋 수정 후에만

빌드에 콘솔 없음 — 화면·조작·오디오 위주로 본다.
