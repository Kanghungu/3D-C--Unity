챕터 1 — 스모크 고정 순서 (메뉴·난이도·빌드)
============================================
프로젝트 **개발 초점은 한 판 데모(Battle Aces)**. 이 목록이 회귀 본전이다.

매 회귀 시 **아래 순서를 바꾸지 말고** 진행한다. Console 은 시작 시 Clear.

(권장) Battle Aces 본진·덱·자원·생산·랠리·업그레이드: **`Assets/Docs/CHAPTER3_SMOKE_CHECKLIST.txt`** 추가 확인.

1) 에디터 준비
   [ ] Unity 프로젝트 열기
   [ ] Console Clear
   [ ] (선택) Game/Campaign/Verify Chapter 1 Build Scenes **또는** Tools/프로젝트/챕터1 씬 (CampaignBuildMenu 와 동일) — 동일 경로 목록 확인

2) CampaignMenu 한 패스 (진입·메뉴 — 챕터 1 마무리)
   [ ] Play → 메인에 **데모 (본전)** 이 **캠페인** 보다 위에 있음
   [ ] **데모** → **← 메인 (Esc)** 또는 **Esc** 로 복귀
   [ ] **캠페인** → **Esc** 또는 **← 메인** 으로 복귀
   [ ] 데모 화면 수치 안내 줄이 버튼의 생산×숫자와 같음(코드 단일 출처)
   [ ] **데모** → 쉬움·보통·어려움 중 하나 → 전투 → 승 또는 패 → 결과 → R 또는 재시작 버튼 또는 **메인 메뉴로**
   [ ] 이 플로우에서 **빨간 에러** 없음

3) NewSampleScene 단독 한 패스
   [ ] Hierarchy/Project 에서 **NewSampleScene** 만 연 뒤 Play (메뉴 거치지 않음)
   [ ] 콘솔에 폴백 데모 로그 한 줄
   [ ] 전투 → 승/패 → 결과 → R / 메인 메뉴로
   [ ] **빨간 에러** 없음

4) 빌드 한 번 (가능할 때)
   [ ] File → Build Settings — CampaignMenu, NewSampleScene 포함·체크됨 (없으면 Game/Campaign/Register Campaign Scenes In Build)
   [ ] Windows 빌드 후 실행 파일로 2) 의 **데모 한 판**만 재현
   [ ] Player.log 에서 **`[DemoBoot]`** 한 줄 확인 (버전·씬·devBuild·gfxPreset 등 — 동일 빌드 비교용)
   [ ] **빨간 에러** 없음 (플레이 중 크래시 없음)

콘솔 기준 (챕터 1)
-------------------
- **수정 대상**: 빨간 **Error** — 스모크 실패로 본다.
- **검토 대상**: 노란 **Warning** — 매번 고칠 필요는 없음. 아래는 보통 **무시 가능**에 가깝다.
  · 에셋 임포터·구버전 API 경고(플레이에 영향 없을 때)
  · 일회성 셰이더·메시 경고(재현 안 되면 메모만)
- **수정 권장** 경고: 같은 경고가 **매 프레임** 또는 **씬 로드마다** 수십 줄 나올 때, NullReference 경로가 전투 루프와 겹칠 때.

씬 목록 유지
------------
- 필수: Assets/Scenes/CampaignMenu.unity, Assets/Scenes/NewSampleScene.unity
- 다른 씬(SampleScene 등)을 빌드에 넣었다면 팀 규칙에 맞게 유지하되, 위 둘이 **빠지지 않게** 할 것.

데모 난이도 수치 (코드 기준, 플레이로 체감 확인)
-----------------------------------------------
- 적 AI 생산 간격 = 기준초 × 배율 (보통 1.0)
  · 쉬움 ×1.52 | 보통 ×1.0 | 어려움 ×0.55
- 개장 자원 부스트(초 × 배율)
  · 쉬움 105×1.55 | 보통 62×1.36 | 어려움 26×1.08

입력·진단 (코드와 동기화 — 회귀 시 참고)
------------------------------------------
- **P** 일시정지, **`[` / `]`** · 숫자패드 **- / +** 배속 — `RtsTimeControl`
- **F1** 도움말, 일시정지 패널 문구 — `DemoPresentationCopy` (`PauseBattleControlsBody`)
- **개발 빌드·에디터**: **F10** 진단 HUD, **F11** FoW 격자 미리보기 (`BattleAcesFogOfWarDebug` — F10 과 분리)
- 설정 **O** → 그래픽 **Performance**(저사양): FoW 시야 갱신이 **최소 2프레임에 1회** (`GetEffectiveVisionUpdateInterval`)

이슈 메모: 씬명, 순서 번호, 콘솔 한 줄, 스크린샷(선택).
