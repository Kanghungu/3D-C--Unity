# 메뉴·데모·캠페인 (참고 매뉴얼)

**개발 핵심은 Battle Aces 한 판 데모**다. 이 문서는 메뉴·진입 확인용이며, **데모(메인 → 데모)** 를 먼저 본다. 캠페인 미션·●○ 는 **옵션·유지** 콘텐츠다.

전투 중 조작·회귀는 루트 `DEVLOG.md` 2절 C 이후.

## 1. 메뉴 씬 (`CampaignMenu`)

### A. 데모 (본전)

1. `Assets/Scenes/CampaignMenu.unity` 를 연 상태로 **Play**.  
2. **메인**에서 **데모 (본전)** 가 위쪽 버튼 — 난이도(쉬움·보통·어려움) → `NewSampleScene` · 브리핑 없음.  
3. **← 메인 (Esc)** 또는 키보드 **Esc** 로 메인 복귀.  
4. 수치 안내 줄은 `MissionDefinition` 과 동기화됨 · 상세는 `CHAPTER1_SMOKE_CHECKLIST.txt`.  
5. 회귀 순서는 **`CHAPTER1_SMOKE_CHECKLIST.txt`**.

### B. 캠페인 (옵션 — 에셋·진행 건드릴 때만)

1. **메인**에서 **캠페인 (옵션)** 진입.  
2. **Console** 빨간 에러 없음.  
3. **Progress [●][○]…** 가 카탈로그 미션 개수와 맞는지.  
4. **Reset Campaign Progress** 시 초기 상태로 돌아가는지.

## 2. 전투 씬 진입

1. **메인 → 데모**: 동일 맵·덱 · 적 생산·개장 부스트만 상이 · ●○ 미반영.  
2. **메인 → 캠페인**: 미션 선택 → (해당 시) 브리핑 → `NewSampleScene` 등.  
3. **상단 UGUI 목표 바** · **좌상 IMGUI** 한글.  
4. **Space / Enter / 좌클릭** — 브리핑 종료(캠페인 미션만). 데모는 즉시 전투.

## 3. 전투 중 조작

게임 안 **F1** 이 가장 최신이다. 상세는 `DEVLOG.md` **2절 C 이후**.
