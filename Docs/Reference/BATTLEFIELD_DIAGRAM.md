# BATTLEFIELD_DIAGRAM.md

## 목적
- 메인 지상전 프로토타입 전장이 어떤 구조로 읽혀야 하는지 한눈에 보여주는 문서
- AI가 전장 배치, 생산 위치, 중앙 목표물, 진영 거리감을 헷갈리지 않게 만드는 기준

## 현재 전장 해석
- 지금 메인 전장은 `SampleScene` 기준의 단일 지상전 씬이다.
- `맵 > 필드 > 전장`처럼 크게 나뉜 구조는 없다.
- 따라서 현재는 `메인 지상전 씬 전체 = 현재 전장`으로 이해하면 된다.

## 원하는 전장 구조
```text
[아군 후방 기지]
      |
[아군 생산 지점 / Foundry]
      |
[아군 집결 구역]
      |
==== 중앙 성지 / Control Node / 첫 교전 구역 ====
      |
[적 전선]
      |
[적 후방 기지]
```

## AI가 전장을 다룰 때 지켜야 할 기준
- 아군과 적은 시작 직후 바로 붙는 느낌보다, 중앙에서 전선을 형성하는 느낌이 우선이다.
- 생산 위치는 "이상한 랜덤 위치"보다 진영 안에서 자연스럽게 읽히는 위치가 좋다.
- 중앙 `Control Node`는 전장의 이유가 보여야 한다.
- 아군 후방, 아군 생산 지점, 중앙 성지, 적 전선, 적 후방이 시각적으로 읽혀야 한다.
- 없는 월드맵 계층을 상상해서 새 시스템을 크게 만들지 않는다.

## 전장 가독성 체크
- 플레이어가 시작하자마자 아군 영역과 적 영역을 구분할 수 있는가
- 중앙 목표물이 왜 중요한지 한눈에 보이는가
- 생산 건물 위치가 전선과 진영 구조 안에서 자연스러운가
- 기지와 생산 지점, 중앙 교전 구역 사이의 관계가 읽히는가
- 테스트맵 느낌보다 RTS 전장 느낌이 더 강한가

## AI에게 바로 보낼 수 있는 문장
```text
`Docs/Reference/BATTLEFIELD_DIAGRAM.md`를 기준으로 메인 지상전 전장을 읽어줘.
지금은 메인 지상전 씬 전체가 하나의 전장이고,
아군 후방 기지 -> 아군 생산 지점 -> 아군 집결 구역 -> 중앙 성지 -> 적 전선 -> 적 후방 기지 흐름이 읽히도록 다뤄줘.
없는 월드맵 구조를 새로 만들지 말고, 현재 씬 안에서 전장 가독성을 높이는 쪽으로 작업해줘.
```
