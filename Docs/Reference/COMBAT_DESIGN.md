# COMBAT_DESIGN.md

## 전투 목표
- 짧고 읽기 쉬운 RTS 전투를 만든다.
- 플레이어가 이동과 집중 공격의 차이를 체감하게 한다.
- 초기 목표는 중간 규모 전투를 안정적으로 성립시키는 것이다
- 장기적으로는 지상전과 작은 함대전이 같은 세계관 안에서 이어져야 한다

## 기본 규칙
- 유닛은 체력을 가진다.
- 유닛은 사거리 안의 적을 공격할 수 있다.
- 공격은 일정 주기로 반복된다.
- 체력이 0이 되면 제거된다.
- 전투 중 제한적인 생산 또는 증원이 가능하다
- 전투는 정면 충돌 외에 포위, 측면, 소모전, 게릴라를 허용한다

## 프로토타입 유닛 역할
- 돌격형
  - 짧은 사거리
  - 높은 체력
  - 전면 교전 담당
- 화력형
  - 긴 사거리
  - 낮은 체력
  - 후방 지원 담당
- 지원형
  - 전투력은 낮음
  - 생산 또는 보조 역할 담당

## 문명 차이 방향
- 일부 문명은 정면 화력과 중장갑에 강하다
- 일부 문명은 기습, 측면, 게릴라에 강하다
- 일부 문명은 극한 행성 적응력과 고기술 무기에 강하다
- 행성 환경과 문명 특성이 맞으면 전투 효율이 올라갈 수 있다

## 전략 레이어 초안
- 점령: 지역을 유지하며 안정적으로 확보
- 약탈: 짧게 공격하고 자원이나 피해만 남기고 철수
- 영향력: 점령하지 않아도 지역 통제력이 남을 수 있음
- 반란 위험: 점령 후 시간이 지나면 저항이 발생할 수 있음

## 전투에서 먼저 확인할 것
- 이동 후 전투가 자연스럽게 이어지는가
- 타겟 전환이 너무 어색하지 않은가
- 한쪽이 빠르게 녹아버리지 않는가
- 10분 이상 진행되어도 지루하지 않은가
- 생산이 전투 흐름을 망치지 않는가
- 중간 규모 병력에서도 측면과 포위가 읽히는가
- 지형이나 문명 특성이 게릴라 감각을 만들어내는가
