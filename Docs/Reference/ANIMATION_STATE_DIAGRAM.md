# ANIMATION_STATE_DIAGRAM.md

## 목적
- 유닛이 어떤 상태 흐름으로 보여야 하는지 정리하는 문서
- AI가 "모델만 좋아지는 것"과 "전투 감각이 살아나는 것"의 차이를 이해하도록 만드는 기준

## 원하는 기본 상태 흐름
```text
Idle
 ├─ Move
 ├─ Attack
 ├─ Hit / Block
 └─ Death
```

## 상태별 기대 감각
- `Idle`
  - 멈춰 있을 때도 완전히 마네킹처럼 보이지 않아야 한다.
- `Move`
  - 미끄러지듯 이동하는 느낌보다 실제 보행/전진 감각이 보여야 한다.
- `Attack`
  - 공격 순간이 분명히 읽혀야 한다.
  - 사격, 반동, 자세 변화 같은 감각이 중요하다.
- `Hit / Block`
  - 맞았는지, 버티는지, 충격을 받았는지가 보여야 한다.
- `Death`
  - 갑자기 사라지는 느낌보다 전투 결과가 보이는 반응이 있으면 좋다.

## 현재 프로젝트에서의 우선순위
- 모든 병종을 한 번에 완성하려 하지 않는다.
- 플레이어 기본 보병 1종과 적 기본 보병 1종부터 기준 상태 감각을 잡는 것이 우선이다.
- RTS 카메라 거리에서도 `지금 이동 중`, `지금 공격 중`, `지금 맞는 중`이 읽혀야 한다.

## 비주얼 방향과 연결
- 플레이어는 중장갑 성전 제국 느낌
- 적은 정면 화력형 문명 느낌
- 장갑, 헬멧, 총기, 실루엣 차이와 함께 모션 차이도 느껴져야 한다.

## 체크 포인트
- 유닛이 이동할 때 이동하는 느낌이 살아 있는가
- 유닛이 공격할 때 공격하는 느낌이 분명한가
- 피격/방어 반응이 없는 마네킹처럼 느껴지지 않는가
- 사망 반응이 전투 결과를 이해하는 데 도움이 되는가

## AI에게 바로 보낼 수 있는 문장
```text
`Docs/Reference/ANIMATION_STATE_DIAGRAM.md`를 기준으로 유닛 상태 감각을 정리해줘.
지금은 모든 병종 전체 애니메이션 완성보다,
플레이어 기본 보병 1종과 적 기본 보병 1종에 `Idle`, `Move`, `Attack`, `Hit 또는 Block`, `Death` 감각을 먼저 만드는 것이 우선이야.
모델만 좋아지는 것이 아니라 전투 중이라는 느낌이 살아나는 방향으로 작업해줘.
```
