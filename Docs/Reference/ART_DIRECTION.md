# ART_DIRECTION.md

## 방향성
- SF와 종교 상징이 섞인 비주얼
- 차가운 금속 구조물 위에 성전, 의식, 문양 요소를 얹는다
- 과한 디테일보다는 실루엣과 색 구분이 중요하다
- 전반 분위기는 어둡고 음침한 우주 성전으로 잡는다
- 장엄함과 공포가 동시에 느껴져야 한다

## 키워드
- 성당형 우주선
- 제단 같은 전투 구조물
- 성광, 문양, 성유물
- 군사 장비와 의식 장식의 결합
- 검은 철재, 붉은 조명, 낡은 성물
- 거대한 우주 사원
- 산업 함대
- 장갑열차 같은 중공업 병기
- 종교 문양이 새겨진 전함

## 색 방향
- 진영 A: 금색, 백색, 짙은 청색
- 진영 B: 적색, 흑색, 황동색
- 중립 환경: 회색 금속, 어두운 우주 배경
- 전체 명도는 낮게 유지하되 유닛 식별성은 확보한다

## 행성 비주얼 방향
- 사막 행성: 먼지, 성지 폐허, 황색 광원
- 빙하 행성: 푸른 금속, 백색 안개, 냉광
- 공업 행성: 굴뚝, 배관, 용광로, 붉은 경고등
- 밀림 행성: 거대한 뿌리, 습기, 녹슨 성역 유적
- 폐허 행성: 부서진 신전, 붕괴한 방어선, 검은 재
- 성지 행성: 거대한 성당형 구조물, 금속과 석재의 혼합

## 프로토타입 원칙
- 일단 구분이 잘 되는 색과 형태를 우선한다
- 고퀄리티 모델링보다 읽기 쉬운 실루엣이 먼저다
- Blender 작업은 모듈형으로 단순하게 시작한다
